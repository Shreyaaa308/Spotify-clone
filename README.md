# Spotify Clone 🎵

A Spotify-inspired music player interface built during my first semester as my introduction to web development.

This was my first hands-on project using **HTML, CSS, and basic JavaScript**. It helped me explore frontend development, understand the fundamentals of web design, and get comfortable with building something from scratch.

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Basics)

## ✨ What I Learned
- Structuring web pages using HTML.
- Styling and designing layouts using CSS.
- Adding basic interactivity using JavaScript.
- Understanding the fundamentals of frontend development.

## 🚧 Known Issues / Improvements

- UI responsiveness and overall styling can be improved.
- More interactive features can be added.

This was one of my earliest projects, built while exploring the basics of web development. Looking back, it was a simple project, but an important starting point in my coding journey.
